* Update Instructions

** Windows Users

Unzip the SVS Management Utility somewhere on your computer then double click the SVS Management Utility.exe file to launch.

** Mac Users

Follow the instruction at https://brew.sh to install Brew.

Install AVRDUDE using Brew:
brew install avrdude

In the terminal, navigate to the directory where you unzipped the SVS Management Utility.app file and run this command:
chmod +x "Svs Management Utility.app/Contents/MacOS/Svs.App"

You only need to run this command once when you download the latest app. After that you can launch the app by double clicking on it.
